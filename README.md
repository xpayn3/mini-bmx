# Mini BMX

Downhill & BMX riding on endless procedural trails: a native PC game made in **Godot 4.7**.

| Folder | What |
|---|---|
| `godot/` | **The game.** Open or run it from here; see [godot/README.md](godot/README.md). |
| `tools/` | Houdini exporters: `export_bmx.py`, `export_dh.py` and `export_helmet.py` write the bike and helmet models into `godot/assets/`. |
| `legacy-threejs/` | The original three.js browser prototype, kept for reference only. It is not developed any more. |
